Blocks you have found

Every hash is tested against both networks at once. The stratum builds a Litecoin block whose coinbase commits to a Dogecoin block, so one scrypt solution can win on either chain — or both. Nothing is split and nothing is shared: this is one miner with two independent chances. Dogecoin's target is the easier of the two, so most wins land there first.
