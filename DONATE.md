# Donate

This package is maintained by [AwfulWaffle Mining](https://www.awfulwafflemining.com) and contributed to the Start9 community registry.

If it saved you some time, the most useful thing you can do costs nothing: run both nodes **unpruned with inbound peers enabled**. Dogecoin and Litecoin both need nodes that serve blocks rather than only consume them, and a node that does is worth more to those networks than a tip is to the packager.

If you would rather send something anyway, open an issue and ask. Addresses published in a repository have a way of going stale, and a dead donation address is worse than none — doubly so here, where Dogecoin and Litecoin addresses look similar enough to confuse, and coins sent to the wrong chain are gone.

## Other ways to help

Worth as much as coin, and often more:

- **Report what breaks.** Open an issue with your StartOS version, the package version and the relevant logs.
- **Say what's confusing.** Wording and layout fixes come from people saying which parts made no sense.
- **Translate it.** Strings live in `startos/i18n/dictionaries/`; adding a language is a pull request with one file. The existing translations have not had a native speaker's review and say so.
- **Tell other solo miners** that merge-mined Dogecoin and Litecoin runs on a Start9 box, with no pool and no fee.

This is a community project. It is not affiliated with the Dogecoin or Litecoin projects.
